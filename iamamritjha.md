## 🚀 Featured Project

### 🏥 LifeLedger — AI Personal Health Intelligence Platform
> **Live Demo:** [https://lifeledger-health.vercel.app/](https://lifeledger-health.vercel.app/)<br />
> **Focus:** Digital Health Vault • Role-Based Access Control • Longitudinal Record Management

A digital health management platform designed to organize and consolidate medical records, appointment schedules, and prescriptions into a unified personal health view.

- **Unified Health Records:** Centralized repository enabling patients to organize, review, and access longitudinal health documents.
- **Access Control &amp; Privacy:** Structured authentication and role-based permissions separating patient and provider workflows with Helmet security headers and API rate limiting.
- **Modern Web Interface:** Interactive, responsive interface built with Next.js and Tailwind CSS for clear clinical data presentation.
- **Document Processing:** Pipeline supporting medical document uploads and PDF document parsing.
